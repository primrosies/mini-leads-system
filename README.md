# Mini Lead Management System (Vanilla JavaScript)

A simple project developed to practice JavaScript fundamentals by solving a real-world inspired problem: managing real estate leads.

This mini system simulates a lead tracking workflow, allowing users to add leads, mark them as captured, and view statistics. All running directly in the browser console.

---

## Project Purpose

- Practice JavaScript fundamentals
- Work with arrays and objects
- Manipulate dynamic data
- Simulate a real system without a backend

This project is part of my learning journey in Software Engineering.

---

## Features

- Add new leads
- List existing leads
- Mark a lead as captured
- View statistics (total leads and captured leads)

---

## Technologies Used

- HTML5
- Vanilla JavaScript

## How to Run

1. Clone the repository:

```bash
git clone <repository-link>
```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Open the browser console (F12 → Console).
5. Run the following commands manually:

```javascript
addLead("Charlie", "Downtown")
addLead("Ana", "Vila Mariana")
showStatistics()
```
